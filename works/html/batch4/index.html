本輪範圍與畢業時的取代關係

SVG 候選稿以靜態圖逐一手繪各狀態；畢業到 HTML/CSS 後一律換成原生互動狀態與真實 DOM。Slider 用原生 <input type="range">（保留瀏覽器的方向鍵／Home／End／PageUp／PageDown／step 語意），範圍變體是兩個各自具可存取名稱、可獨立鍵盤操作的 range 控制項，不是兩個畫出來的 thumb。Accordion 用語意標題內含 <button>，以 aria-expanded／aria-controls 關聯 panel。Popover 用原生 Popover API（popover="auto"）取得 Esc、面板外點擊關閉與焦點自動回到 trigger，定位／翻轉／位移另以 JS 對 viewport 實算。Date / Time picker 組合上述 Popover 與既有 Text input／Icon button，月曆是 role="grid" ＋ roving tabindex。

Slider 幾何說明：審查通過的 SVG 定義 thumb 中心 = 值百分比 × 軌道長度（值 40 時中心落在 320px 的第 128px）。瀏覽器原生 range 預設會把 thumb 內縮，使中心只在 寬度 − thumb 範圍內移動（同樣條件下會落在 130.4px）。為了與核准視覺一致，本檔把 <input> 左移一個 thumb 半徑並外擴一個 thumb 直徑，讓 thumb 中心走完整軌道長度；代價是 0%／100% 時 thumb 會突出軌道兩端各 12px，容器已預留內距。

刻意未實作、待審查決定的項目：Date / Time picker 的日期欄位目前是 readonly，值只能由月曆設定。自由輸入需要日期解析與「無效／不完整輸入」的視覺，而該視覺在 SVG 審查時已明確標記為「待 G1／G2 決定，不先預設」，因此這裡不自行發明錯誤樣式。Accordion 的開闔沒有加動畫：motion.duration-base／easing-standard 在 token 檔仍標記 candidate，靜態 SVG 無法用來重新核對動效值，依 AGENTS.md「candidate 值不得原封不動沿用」的規則，寧可不動畫也不引用未驗證的值。

單開（一次只展開一項）

間距一律取自 8px 級距；版面用 flex／grid 排，不用固定座標。

內文對比至少 4.5:1；浮動面板上的次要文字改用 gray-600，不用 foreground-subdued（它與面板同色會直接消失）。

圖示線寬固定 2px，端點與轉角一律圓角。

展開任一項會收合其他項；焦點留在被按下的 trigger 上，不移動到 panel

多開（可同時展開多項）

同一狀態在不同元件不得使用不同名稱（例如 off 與 inactive 併存）。長標題在此示意兩行內容的密度。

本元件目前不做開闔動畫，因為動效 token 仍是未驗證的 candidate。

所有 icon-only 按鈕需有可存取名稱，裝飾性圖示標記 aria-hidden。

第 1、3 項同時展開；末項下方沒有額外分隔，區塊邊界就是最後一個圓角列

issue #12 · Text input＋Icon button 作為 trigger，面板組合 Popover · 40px 日期格 · 單日／範圍／時間 · 日期格式固定 YYYY/MM/DD；時間值固定 24 小時制 HH:MM，顯示由原生控制項依使用者地區設定決定（zh-TW 下會顯示「上午／下午 hh:mm」）

日期範圍：再選一次會重新開始新範圍。只選到起點的暫態下，「套用」原生停用，避免送出半個範圍

disabled：欄位與圖示按鈕同時原生停用，兩者皆不可聚焦

月曆鍵盤模型（roving tabindex）

  • 方向鍵：前後一天／前後一週
  • Home／End：跳到該週的第一天／最後一天
  • PageUp／PageDown：上一個月／下一個月
  • Enter／Space：選取目前聚焦的日期
  • Esc：關閉面板，焦點回到 trigger
