本輪範圍

第三批（8 類）目前完成第 1-2 個元件：Progress / Spinner / Loading、Search field。已實作互動：spinner 以 CSS animation 持續旋轉（非 SVG 快照）、determinate 進度條會自動示範 0→100% 的真實 width 過渡、indeterminate 進度條以持續滑動的區段示意、error 進度條有「重試」示範、full-page loading 有「取消」／「重新示範」示範。prefers-reduced-motion：批次二既有的全域規則把所有動畫時長硬壓到 0.01ms，這對「一次性開闔轉場」正確，但套用在這裡的持續循環動畫（旋轉、滑動）上會變成極速閃爍而不是停止，本檔案另外覆寫為直接停在靜態畫面（見 styles.css 對應註解）。依 GitHub issue #13 的決議，本元件審查通過後已回填 loading 視覺到 works/html/batch2/ 的 List／Data table／Kanban column（同一批 PR 完成，見 docs/design-system-v0.1-batch2-draft.md 跨元件設計決策，以及該檔案為權威來源，此處不重複維護狀態）。

Search field（issue #6）延伸 Text input 的 token 與結構。SVG 候選稿原本用四張靜態圖畫 empty／filled／focused／disabled，畢業到 HTML/CSS 後改用真正的原生互動狀態：focus 邊框改用 :focus-within 即時觸發（不需要另外準備一張「focused」快照）、清除按鈕的出現／隱藏與 disabled 的變暗都是即時的 input 事件與原生 :disabled／:has()，取代候選稿手繪每個狀態的做法。
